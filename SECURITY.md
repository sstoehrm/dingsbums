# Security policy

## Supported versions

Only the latest release gets fixes. `dingsbums update` installs it.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/sstoehrm/dingsbums/security/advisories/new)
(the repository's Security tab). Don't open a public issue.

Include what is affected, how to reproduce it and what an attacker gains.

## What to expect

- An answer within 7 days.
- A fix or a plan within 30 days of confirming the report.
- The advisory is published once a fixed release is out, crediting you unless
  you'd rather not be named.
